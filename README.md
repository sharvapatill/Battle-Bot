# Red Raider BattleBot

A fully IR controlled combat rover built using TI MSP430 microcontrollers for competitive robotics applications. The project integrates embedded systems, motor control, IR communication, and mechanical attack mechanisms into a single battle ready platform.

## Features
- Dual MSP430 microcontroller architecture for IR transmitter receiver control
- Custom 38 kHz IR signal encoding to prevent interference
- PWM based differential motor control using L298N H Bridge
- Front ramp and punch attack mechanisms with independent linear actuation
- Verified IR communication range up to 15 ft

## System Overview
- **Microcontrollers:** TI MSP430
- **Communication:** Infrared (38 kHz carrier)
- **Motor Driver:** L298N H Bridge
- **Development Environment:** Code Composer Studio
- **Testing Tools:** Oscilloscope for signal verification

## Mechanical Design
- Front ramp for lifting or destabilizing opponents
- Punch mechanism for direct offensive engagement
- Balanced chassis optimized for stability and maneuverability

## Testing and Validation
- Oscilloscope based verification of IR carrier frequency and burst timing
- PWM tuning for smooth speed control and directional accuracy
- Communication reliability testing under varying environmental conditions

## Skills Demonstrated
- Embedded C programming on MSP430
- PWM motor control and H Bridge interfacing
- IR communication protocol design
- Hardware debugging using oscilloscopes
- Electromechanical system integration
